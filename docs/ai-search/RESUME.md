## Inviolable rules

1. **Never delete `src/lib/search/normalize.ts` entirely** — `tokensOf` and a few helpers are still used by Phase 2 fallbacks.
2. **Never run extraction at request time** — it MUST be a build/scrape-time step. Per-query LLM calls would 100× the bill.
3. **Always cache by content hash** — `extract-products.ts` skips deals whose title+description hash already exists in `extracted.json`. Don't disable this without explicit user approval.
4. **Never check `extracted.json` cost into PRs** — log spend in `COST-LOG.md` so future sessions can see the rolling total.
5. **Don't change the public API contract** of `src/lib/search/index.ts` (`SearchOutput`, `ProductGroup`, `StoreOffer`) without a migration note. The frontend depends on it.
